
# Test Cases – Eco-Ride Project

## 1. Purpose
Test cases provide **step-by-step instructions** for validating system functionality based on requirements and use cases.

---

### TC-01: Rider Registration

| Step | Action | Expected Result |
|------|-------|----------------|
| 1 | Open Eco-Ride app | App loads successfully |
| 2 | Tap 'Register' | Registration form appears |
| 3 | Enter valid details | Form validates input |
| 4 | Submit form | Account is created, confirmation message shown |

---

### TC-02: Book a Ride

| Step | Action | Expected Result |
|------|-------|----------------|
| 1 | Log in as rider | Login successful |
| 2 | Enter pickup & destination | System displays available vehicles |
| 3 | Select vehicle & confirm | Ride is booked, driver notified |
| 4 | View ride status | Real-time tracking visible |

---

### TC-03: Payment Processing

| Step | Action | Expected Result |
|------|-------|----------------|
| 1 | Complete ride | Fare calculated automatically |
| 2 | Select payment method | Payment processed successfully |
| 3 | Confirmation message | Payment confirmed, receipt displayed |
