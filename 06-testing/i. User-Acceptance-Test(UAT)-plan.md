
# User Acceptance Testing (UAT) plan – Eco-Ride Project

## 1. Purpose
The User Acceptance Testing (UAT) plan defines how the Eco-Ride system will be tested by **end users** to ensure it meets business requirements and is ready for production.

---

## 2. Objectives
- Validate functional and non-functional requirements
- Confirm system usability and performance
- Identify defects before production
- Obtain formal user sign-off

---

## 3. Scope
- Rider Mobile App
- Driver Mobile App
- Admin Dashboard
- Payment Gateway integration
- GPS & Mapping services

---

## 4. Roles & Responsibilities

| Role | Responsibility |
|------|----------------|
| Business Analyst | UAT planning, coordination, and reporting |
| QA Team | Provide test support and assist in defect logging |
| Users (Riders & Drivers) | Execute test scenarios and provide feedback |
| Project Manager | Approve UAT completion and sign-off |
| Technical Lead | Provide technical support for defects |

---

## 5. Entry & Exit Criteria

**Entry Criteria**
- All functional and non-functional requirements documented
- Development complete and QA-tested
- Test environment ready

**Exit Criteria**
- All critical defects resolved
- UAT sign-off obtained from stakeholders
- Updated defect log
