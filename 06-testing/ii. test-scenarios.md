
# Test Scenarios – Eco-Ride Project

## 1. Purpose
Test scenarios describe **high-level testing objectives** for each major function of the Eco-Ride platform.

---

## 2. Rider Scenarios
1. User registration and login
2. Search for available rides
3. Book a ride
4. Track driver in real time
5. Complete payment
6. Rate and review ride

---

## 3. Driver Scenarios
1. Driver registration and login
2. Accept ride requests
3. Start and complete ride
4. View earnings summary
5. Update vehicle availability

---

## 4. Admin Scenarios
1. Manage users
2. Manage vehicles
3. Monitor ride operations
4. Generate reports
5. Approve or reject driver accounts
