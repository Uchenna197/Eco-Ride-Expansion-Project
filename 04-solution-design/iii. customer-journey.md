
# Customer Journey – Eco-Ride

## 1. Purpose
This document maps the **end-to-end journey of a rider** interacting with the Eco-Ride platform.

---

## 2. Journey Stages

| Stage | User Action | System Touchpoint | User Feeling |
|----|------------|------------------|-------------|
| Awareness | Opens app | Landing screen | Curious |
| Booking | Enters trip details | Ride search | Confident |
| Confirmation | Confirms booking | Ride confirmation | Reassured |
| Ride | Tracks driver | Live tracking | Comfortable |
| Payment | Completes payment | Payment gateway | Secure |
| Feedback | Rates ride | Rating screen | Empowered |

---

## 3. Key Moments That Matter
- Ride availability display
- Fare transparency
- Driver arrival time
- Payment confirmation

---

## 4. Pain Point Resolution
Eco-Ride addresses:
- Uncertainty in ride availability
- Pricing disputes
- Safety concerns
- Payment friction
