
# Change Management Plan – Eco-Ride Project

## 1. Purpose
Defines **how project changes will be requested, assessed, approved, and implemented** to control scope, cost, and timeline.

---

## 2. Change Request Process
1. Submit change request form (description, reason, impact)
2. BA reviews alignment with requirements
3. PM evaluates impact on timeline, budget, and resources
4. Change Control Board (CCB) approves or rejects
5. Approved changes implemented by development or operations
6. Documentation updated (FSD, RTM, delivery plan)

## 4. Roles & Responsibilities
- **Business Analyst:** Evaluates requirement alignment  
- **Project Manager:** Assesses impact and facilitates CCB  
- **CCB:** Approves or rejects changes  
- **Development / QA / OPS:** Implements approved changes
