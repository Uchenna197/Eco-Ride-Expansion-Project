# Stakeholder Analysis

This folder identifies all stakeholders involved in the Eco-Ride project and defines how they are managed and engaged.

## Key Artifacts
- Stakeholder register
- RACI matrix
- Power–interest matrix
- Communication plan

## Stakeholder Groups
- City authorities
- Operations team
- Technology vendors
- End users (riders)

## Outcome
Improved alignment, reduced resistance, and effective communication throughout the project lifecycle.
